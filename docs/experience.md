# Relevant Experience

## HEAN

HEAN is a private event-driven AI/algorithmic trading platform.

### Problem

Build a system that can continuously collect external signals, process them through strategy and decision layers, execute trades under risk controls and expose operational state for monitoring.

### Stack

- Python / asyncio
- FastAPI
- WebSocket
- Redis
- PostgreSQL
- Docker
- React / Vite
- Pydantic
- pytest
- C++ / Rust for selected performance-sensitive components

### Relevant engineering experience

The project required integration boundaries, asynchronous processing, event routing, persistent state, risk controls and observability. This maps closely to an AI-operator architecture: external systems are isolated behind adapters, orchestration is explicit, and operational state is measurable.

The repository is private, so this test contains only a high-level description rather than internal source code or credentials.
